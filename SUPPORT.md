# Support

Thanks for using DiffMerge. Here's how to get help.

## Report a bug or request a feature

Open an issue in this repository:

**https://github.com/bingq/diffmerge/issues/new**

Please include:

- macOS version (Apple menu → About This Mac)
- DiffMerge version (DiffMerge menu → About DiffMerge)
- Steps to reproduce the issue
- What you expected to happen vs what actually happened
- Screenshots if they help

## Direct contact

For questions that aren't bug reports:

Email: geldqb@gmail.com

Please allow 1–3 business days for a response.

## App Store reviews

If something isn't working, please **open an issue here first** — I can usually fix bugs quickly, and an updated app is more helpful than a one-star review.

## Frequently asked questions

**Q: Does DiffMerge send any data anywhere?**
A: No. See the [Privacy Policy](PRIVACY.md).

**Q: Does it integrate with Git?**
A: Not directly in v0.5. Git integration is on the roadmap.

**Q: Does it support three-way merge or folder diff?**
A: Also on the roadmap.

**Q: Why only text files?**
A: DiffMerge is a text diff tool. Binary file comparison is out of scope.

**Q: Can I request a feature?**
A: Yes — please open an issue with the `enhancement` label.

**Q: Is the source code available?**
A: The source code is proprietary. Documentation lives here; the app itself ships through the Mac App Store.

**Q: How do I restore my purchase on a new Mac?**
A: Sign in with the same Apple ID, reinstall from the Mac App Store — any purchases are automatically restored.
